## Overview

The GenAI Chat tab provides a conversational AI interface that connects to Infor's GenAI backend. It supports session management, message history, and streaming responses.

## Capabilities

### Session Management
- Create new chat sessions
- Browse and resume previous sessions (sorted by last updated)
- View full message history for any session

### Streaming Responses
- Real-time streaming of AI responses via SSE
- Human and AI messages displayed in a chat UI
- Enter to send, Shift+Enter for newline

## Usage

1. Type a message and press **Enter** to start a new session
2. Click the sessions panel to browse or resume previous conversations
3. Click **New Chat** to start fresh
